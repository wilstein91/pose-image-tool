# 원하는 포즈로 이미지 만드는 도구

## 도구 설명
- 참조 사진에서 인물의 **자세(관절 구조)만** 뽑아내고, 인물·의상·배경·화풍은 프롬프트대로 새로 그려주는 Colab 노트북입니다.
- Stable Diffusion 1.5 + ControlNet(OpenPose)를 쓰며, 무료 Colab T4 GPU에서 한 장에 10~20초 걸립니다.

## 사용법
1. `pose_tool.ipynb` 를 Colab에서 엽니다. (구글 드라이브에서 파일 우클릭 → 연결 프로그램 → Google Colaboratory) 연 뒤 **런타임 → 런타임 유형 변경 → T4 GPU** 로 설정합니다.
2. STEP 0부터 아래로 순서대로 실행합니다. STEP 3에서 참조 사진을 지정하고, STEP 5에서 뽑힌 스켈레톤이 원본 자세와 닮았는지 확인한 뒤, **STEP 7에서 프롬프트만 바꿔** STEP 8에서 생성합니다.
3. 결과는 프로젝트 폴더의 `outputs/` 에 `result_seed{seed}_cn{자세강도}_g{충실도}.png` 이름으로 저장됩니다. 같은 이름이 있으면 `-1`, `-2` 가 붙습니다.

## 테스트 결과
- 포즈 1 (`samples/pose_01.png`, 기구에 등을 대고 누운 자세) → 프롬프트: *(실제 사용한 프롬프트 기입)* → 결과: **잘 됨.** 수평으로 뜬 실루엣 인물로 생성 (`outputs/result_seed125_cn1.2_g9.png`, seed 125 / 자세강도 1.2 / 충실도 9)
- 포즈 2 (`samples/pose_02.png`, 서서 치맛단을 잡은 전신 자세) → 프롬프트: *(미테스트)* → 결과: 스켈레톤 추출까지 정상 확인

## 한계
- **애니메이션·일러스트 참조는 관절 인식률이 낮습니다.** OpenPose가 실사 사진으로 학습된 모델이라, 머리가 크고 명암이 평평한 그림체에서 자세를 놓칩니다. 실사 사진을 쓰는 편이 안정적입니다.
- **손가락과 얼굴은 전달되지 않습니다.** OpenPose가 몸통·팔다리 관절 18곳만 잡기 때문에 손이 자주 뭉개집니다. seed를 바꿔 여러 장 뽑아 고르는 편이 빠릅니다.
- **참조 사진의 소품은 따라오지 않습니다.** 관절 좌표만 넘어가므로, 의자나 기구가 필요하면 프롬프트에 직접 써야 합니다. 안 쓰면 허공에 뜬 인물이 나옵니다.
- **가로로 긴 사진(16:9 등)은 인물이 작게 잡힙니다.** 인물 주변을 잘라내야 하며, 노트북 STEP 5-4가 이를 자동으로 해줍니다.
- 무료 T4에서는 512px 내외가 한계입니다. 그보다 크게 만들면 인물이 둘로 복제되는 현상이 자주 나타납니다.
